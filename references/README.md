Os PDFs enviados pelo usuário ficam fora do Git e do ZIP de código. Não são dependências de execução da API. Preserve-os também em armazenamento externo autorizado; o checkpoint de código não os protege.

A organização de pastas não altera essa proveniência nem habilita novas regras. Ambos os hashes foram conferidos após a movimentação em 23/10/2026. Marcadores de download `:Zone.Identifier` foram removidos; não fazem parte dos PDFs.
