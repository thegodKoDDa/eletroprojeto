# Relatar uma vulnerabilidade

Comunique ao responsável pelo repositório por um canal privado, com os passos mínimos para reprodução, o impacto observado e a versão afetada. Use dados fictícios; não inclua credenciais, bancos de projetos ou documentos pessoais.

O código é público; dados e credenciais de cada instalação permanecem locais. A distribuição padrão atende somente o próprio computador. Configuração de acesso, HTTPS, sessões e limites de segurança estão em [docs/security.md](docs/security.md).
